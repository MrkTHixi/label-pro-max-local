Label Pro Max Local
ติดตั้งครั้งแรกจนถึงใช้งานจริง

ระบบพิมพ์ฉลากภาษาไทยขนาด 100 × 150 มม. ทำงานในเครื่องประจำสาขา เมื่อเตรียมระบบครั้งแรกแล้ว การค้นหาและพิมพ์ประจำวันใช้งานได้โดยไม่ต้องเชื่อมต่ออินเทอร์เน็ต

เตรียมก่อนเริ่ม

  • เครื่อง Windows 64 บิต แนะนำ Windows 11 บนเครื่อง x64 และบัญชีผู้ใช้ที่จะใช้โปรแกรมจริง
  • อินเทอร์เน็ตสำหรับติดตั้งครั้งแรก ดาวน์โหลดโปรแกรม และอัปเดต
  • Google Chrome และเครื่องพิมพ์ฉลาก พร้อมไดรเวอร์ของรุ่นที่ใช้งาน
  • ม้วนฉลาก 100 × 150 มม. และไฟล์ Excel ลูกค้า ถ้าต้องการนำเข้าข้อมูล
  • โฟลเดอร์ที่ผู้ใช้เขียนไฟล์ได้ เช่น C:\LabelProMaxLocal\label-pro-max-local ไม่วางไว้ใน Program Files หรือเปิดใช้งานจากไฟล์ ZIP
เลือกโค้ดรุ่นที่ถูกต้อง
คู่มือนี้ตรงกับสาขา codex/windows-launcher-thai-print ซึ่งมีตัวเปิดแบบซ่อน รายการติดดาว และฉลากภาษาไทยที่แก้แล้ว ขณะจัดทำยังไม่ได้รวมการแก้ไขนี้เข้า main

ลำดับการติดตั้ง

ติดตั้ง Chrome และไดรเวอร์ → รับโค้ด → เปิด start-label-pro-max-local.vbs ครั้งแรก → ตั้งผู้ส่งและเครื่องพิมพ์ → นำเข้าลูกค้า → ทดลองพิมพ์ 1 ใบ

ไม่ต้องติดตั้ง Node.js เอง ตัวเปิดเตรียมเครื่องมือที่จำเป็นให้โดยอัตโนมัติเมื่อไม่มีรุ่นที่ใช้งานได้

1. ลงโปรแกรมและรับโค้ด

ติดตั้ง Chrome และเครื่องพิมพ์

  1. ดาวน์โหลด Chrome จาก google.com/chrome แล้วเปิดไฟล์ติดตั้ง ทำตามขั้นตอนบนหน้าจอ
  2. ติดตั้งไดรเวอร์เครื่องพิมพ์จากไฟล์ที่ผู้ขายหรือผู้ผลิตให้มา เลือกให้ตรงรุ่น ไม่จำเป็นต้องใช้ชื่อ TP518G เหมือนเครื่องต้นทาง
  3. ต่อ USB เปิดเครื่องพิมพ์ ใส่ฉลาก และตรวจว่า Windows มองเห็นเครื่องพิมพ์ในหน้า Printers & scanners
  4. เปิด Printing preferences ของเครื่องพิมพ์ ตั้งกระดาษ 100 × 150 mm และทำการปรับตรวจจับฉลากตามคู่มือเครื่องพิมพ์

วิธี A: ติดตั้งด้วย Git เพื่อใช้ปุ่มอัปเดตได้

  1. ดาวน์โหลดและติดตั้ง Git for Windows ใช้ค่าติดตั้งเริ่มต้น แล้วปิดและเปิด PowerShell ใหม่หลังติดตั้ง
  2. ใช้ File Explorer สร้างโฟลเดอร์ C:\LabelProMaxLocal
  3. เปิด PowerShell แล้วคัดลอกคำสั่งด้านล่างทีละบรรทัด ขั้นตอนนี้ใช้เฉพาะตอนรับโค้ดครั้งแรก
cd C:\LabelProMaxLocal
git clone --branch codex/windows-launcher-thai-print --single-branch https://github.com/MrkTHixi/label-pro-max-local.git label-pro-max-local

หาก GitHub ขอเข้าสู่ระบบ ให้ใช้บัญชีที่มีสิทธิ์เข้าถึงโปรเจค เมื่อเสร็จแล้วปิด PowerShell ได้

วิธี B: ดาวน์โหลด ZIP เพื่อเริ่มใช้งานง่าย

  1. เปิด หน้าโปรเจคสาขาที่แก้ไข ถ้าเป็นโปรเจคส่วนตัวต้องเข้าสู่ระบบ GitHub
  2. เลือก Code → Download ZIP แล้วแตกไฟล์ทั้งหมด
  3. ย้ายโฟลเดอร์ที่มี start-label-pro-max-local.vbs และ package.json ไปที่ C:\LabelProMaxLocal\label-pro-max-local
ZIP เปิดและพิมพ์ได้ แต่ปุ่มอัปเดตจาก GitHub ต้องใช้โปรเจคที่ clone ด้วย Git หากใช้ ZIP ต้องให้ผู้ดูแลอัปเดตโค้ดโดยรักษา data/ และ backups/ เดิมไว้

2. เปิดระบบและตั้งค่า

  1. เปิดโฟลเดอร์โปรเจค แล้วดับเบิลคลิก start-label-pro-max-local.vbs จากบัญชี Windows ที่จะใช้ประจำ
  2. รอหน้าต่างเตรียมระบบ ครั้งแรกต้องใช้อินเทอร์เน็ตและอาจใช้เวลาหลายนาที ตัวเปิดเตรียม Node.js และตัวสร้างฉลากให้ ไม่ต้องเปิดไฟล์ซ้ำระหว่างเตรียม
  3. เมื่อเว็บและตัวพิมพ์พร้อม ระบบเปิดหน้าต่างโปรแกรมให้ ที่อยู่คือ http://localhost:3000
  4. ตัวเปิดสร้างทางลัด Label Pro Max Local บน Desktop และลงทะเบียนเริ่มระบบเบื้องหลังเมื่อเข้า Windows ของผู้ใช้คนนี้ หากไม่เห็นทางลัด ให้ไป ตั้งค่า → สร้างทางลัดและเปิดพร้อม Windows

ข้อมูลผู้ส่งและสาขา

  1. กดปุ่มตั้งค่า รูปเฟืองด้านบน
  2. กรอกชื่อผู้ส่ง เบอร์โทร ที่อยู่ และที่อยู่เพิ่มเติม แล้วกดบันทึกข้อมูลผู้ส่ง
  3. กรอกชื่อสาขา เลือกชื่อเครื่องพิมพ์จากรายการของ Windows แล้วกดบันทึกตั้งค่า
  4. ดูสถานะระบบพิมพ์ ต้องพร้อมใช้งาน หากแสดงโหมดทดลอง จะไม่มีการส่งพิมพ์จริง ให้ผู้ดูแลตรวจการตั้งค่าระบบ
ชื่อเครื่องพิมพ์ต้องตรงกับ Windows
เลือกชื่อที่ติดตั้งบนเครื่องใหม่จริง เช่น TP518G หรือชื่ออื่นที่ปรากฏในรายการ อย่าคัดลอกชื่อจากเครื่องเก่าโดยไม่ตรวจสอบ

เปิดและปิดในแต่ละวัน

สิ่งที่ทำผลที่เกิดขึ้น
เข้า Windowsบริการเริ่มเบื้องหลัง ไม่เปิดหน้าโปรแกรมเอง
เปิดทางลัด Label Pro Max Local บน Desktopตรวจและเริ่มบริการให้พร้อม แล้วเปิดโปรแกรม ไม่มี terminal ค้าง
กด X ปิดหน้าต่าง Chromeปิดเฉพาะหน้าต่าง บริการและคิวพิมพ์ยังทำงาน
ตั้งค่า → ปิดระบบ หรือ stop-label-pro-max-local.vbsรอส่งงานที่กำลังพิมพ์ให้จบ แล้วหยุดเว็บและตัวพิมพ์

หากใช้ทางลัดที่ติดตั้งจาก Chrome แล้วเข้าไม่ได้ ให้ใช้ทางลัด Label Pro Max Local เพื่อเริ่มบริการก่อน ลิงก์ localhost อย่างเดียวไม่เริ่มบริการที่ปิดอยู่

3. เพิ่มลูกค้าและนำเข้า Excel

รูปแบบไฟล์ Excel

ตั้งชื่อชีตว่า PrintLabel และใช้ 4 คอลัมน์ตามลำดับนี้

คอลัมน์ข้อมูลตัวอย่างสมมติ
Aชื่อย่อที่ใช้ค้นหา ไม่พิมพ์บนฉลากโรงงาน
Bชื่อร้าน / ผู้รับ ที่พิมพ์บนฉลากบริษัท ตัวอย่าง จำกัด
Cที่อยู่ครบพร้อมรหัสไปรษณีย์99 ถนนตัวอย่าง กรุงเทพฯ 10100
Dชื่อผู้ติดต่อและเบอร์โทรคุณตัวอย่าง 080-000-0000
  1. ไปหน้า ลูกค้า → นำเข้า Excel เลือกไฟล์ แล้วรอข้อความจำนวนรายการที่นำเข้า
  2. ตรวจชื่อร้านและที่อยู่ในรายการ แถวหัวตารางที่มีคำว่า “ชื่อสถานที่” และแถวที่ A ว่างจะถูกข้าม
  3. การนำเข้าเพิ่มรายการใหม่ ไม่ตรวจรายการซ้ำอัตโนมัติ อย่านำเข้าไฟล์เดิมซ้ำโดยไม่ได้ตรวจรายการ

เพิ่มรายคนได้ที่ ลูกค้า → เพิ่มลูกค้าใหม่ กรอกชื่อย่อ ชื่อผู้รับ ที่อยู่ ติดต่อ แล้วบันทึก กรอกคอลัมน์ B ให้ครบ เพราะระบบจะไม่ใช้ชื่อย่อ A แทนชื่อผู้รับบนฉลาก

ค้นหาและใช้รายการติดดาว

  1. ค้นหาด้วยชื่อย่อ ชื่อลูกค้า หรือข้อมูลติดต่อ คลิกหนึ่งครั้งเพื่อดูตัวอย่างฉลาก
  2. กด ☆ ข้างลูกค้าเพื่อปักหมุด รายการใช้บ่อยจะแสดงชื่อย่อคอลัมน์ A เป็นปุ่มเล็กเรียงแนวนอนเหนือช่องค้นหา
  3. ดับเบิลคลิกชื่อในรายการค้นหาหรือรายการปักหมุด หรือกดรูปเครื่องพิมพ์ เพื่อเปิดตัวเลือกพิมพ์
  4. กด ★ เพื่อเลิกปักหมุด รายการดาวยังอยู่เมื่อปิดและเปิดโปรแกรมใหม่

ทดลองครั้งแรก 1 ใบ

เลือกข้อความ จำนวน 1 ใบ และชื่อผู้สั่ง ตรวจตัวอย่างแล้วกดสั่งพิมพ์ ดูหน้าคิวและรอฉลากออกจริง ตรวจขนาด สระ วรรณยุกต์ ชื่อผู้รับ ที่อยู่ และการตัดฉลาก ก่อนพิมพ์หลายใบ

จำนวนเลือกได้ 1-20 ใบต่อคำสั่ง สถานะ “ส่งงานพิมพ์แล้ว” หมายถึงโปรแกรมส่งงานเสร็จ ต้องดูฉลากจริงเพื่อยืนยันว่ากระดาษออกถูกต้อง

หน้าคิว: ยอดรวมส่งพิมพ์สำเร็จนับจำนวนใบของทุกงานสำเร็จ เลือกงานล้มเหลวทีละรายการหรือเลือกทั้งหมด แล้วกดล้างและยืนยันได้ งานสำเร็จและยอดรวมยังอยู่

4. สำรอง อัปเดต และล้างข้อมูล

สำรองข้อมูลก่อนย้ายเครื่องหรืออัปเดต

  1. ไป ตั้งค่า → สำรองข้อมูลตอนนี้ รอแล้วตรวจสถานะสำรองล่าสุดในหน้าเดิม
  2. เปิดโฟลเดอร์ backups ของโปรเจค ตรวจว่าไฟล์ .db ชุดล่าสุดมีวันที่ตรงกับการสำรอง
  3. คัดลอกไฟล์สำรอง .db ไป USB หรือพื้นที่เก็บสำรองที่ดูแลไว้ ข้อมูลที่อยู่เฉพาะเครื่องเดียวไม่ช่วยเมื่อเครื่องนั้นเสีย

สำรองเก็บลูกค้า ดาว ผู้ส่ง ตั้งค่า และประวัติพิมพ์ ไม่จำเป็นต้องกรอกที่อยู่ repo สำรองเพื่อสำรองในเครื่อง ถ้าจะส่งขึ้น Git ให้ใช้ repo สำรองแยกจาก repo โค้ดและตั้งสิทธิ์เข้าถึงข้อมูลลูกค้าให้เหมาะสม

เครื่องใหม่เริ่มว่าง หรือย้ายข้อมูลเดิม?

  • สาขาใหม่: ติดตั้งโค้ดแล้วนำเข้า Excel ของสาขานั้น ไม่ต้องคัดลอกฐานข้อมูลเก่ามา
  • ย้ายเครื่องเดิม: ติดตั้งและเปิดเครื่องใหม่ครั้งแรกให้เสร็จ ปิดระบบทั้งสองเครื่อง แล้วให้ผู้ดูแลกู้ไฟล์ .db ที่สำรองจากเครื่องเก่าด้วย scripts/restore.mjs วิธีนี้แทนข้อมูลทั้งชุด ไม่ใช่รวมลูกค้าสองเครื่อง

สำหรับผู้ดูแลที่มี Node.js/npm ให้เปิด PowerShell ในโฟลเดอร์โปรเจคใหม่หลังปิดระบบ แล้วใช้:

npm run restore -- "D:\Label Pro Max Local-backup\ชื่อไฟล์สำรอง.db"

ถ้าใช้ Node แบบ portable ให้เรียก node.exe ใน .runtime\node-v24...\ ตามชื่อโฟลเดอร์จริงกับ scripts\restore.mjs และพาธไฟล์สำรอง ตัวกู้คืนตรวจไฟล์และสำรองข้อมูลเครื่องใหม่ก่อนแทนที่ หลังเปิดใหม่เลือกเครื่องพิมพ์ของเครื่องใหม่อีกครั้ง ไม่คัดลอกเฉพาะ labelpro.db ระหว่างระบบเก่ากำลังทำงาน

อัปเดตและล้างลูกค้า

อัปเดต: สำรองและจัดการคิวให้จบ เชื่อมอินเทอร์เน็ต ไป ตั้งค่า → อัปเดตแอปจาก GitHub รอผลและเปิดทางลัดอีกครั้งถ้าจำเป็น ใช้ได้กับโปรเจคที่ clone ด้วย Git และไม่มีไฟล์แก้ไขค้าง

ล้างทั้งหมด: ไป ลูกค้า → ล้างข้อมูลลูกค้าทั้งหมด ตรวจจำนวนและผลกระทบ พิมพ์ “ล้างข้อมูล” แล้วกดยืนยัน ระบบสำรองก่อนลบ ถ้าสำรองไม่สำเร็จจะไม่ล้าง ลบลูกค้ารวมรายการที่ปิดใช้งานและดาว แต่ยังเก็บผู้ส่ง ตั้งค่า ประวัติพิมพ์ และไฟล์สำรอง

ข้อมูลแต่ละเครื่องแยกกัน ไม่มีการซิงค์ระหว่างสาขา5 / 7

ผู้ดูแลทำก่อน

บันทึกและส่งโค้ดรุ่นใหม่ขึ้น GitHub ในสาขาที่เครื่องผู้ใช้งานติดตามอยู่ ปุ่มอัปเดตดึงจากสาขานั้น ไม่สลับไป main เอง เครื่องที่ติดตั้งตามคู่มือนี้ติดตาม codex/windows-launcher-thai-print หากย้ายการปล่อยรุ่นไป main ต้องให้ผู้ดูแลเปลี่ยนสาขาของเครื่องปลายทางก่อน

ผู้ใช้งานที่ติดตั้งด้วย Git ทำตามนี้

  1. เปิด Label Pro Max Local และเชื่อมต่ออินเทอร์เน็ต ต้องมี Git และสิทธิ์อ่าน repo หากเป็นโปรเจคส่วนตัวให้ผู้ดูแลเตรียมการเข้าสู่ระบบ GitHub ไว้ก่อน
  2. ไป ตั้งค่า → สำรองข้อมูลตอนนี้ รอและตรวจสถานะสำรองล่าสุดว่าเรียบร้อย
  3. ไปหน้าคิว รอให้งานรอพิมพ์และงานกำลังพิมพ์หมด รวมถึงรอการนำเข้าลูกค้าให้จบ
  4. ไป ตั้งค่า → อัปเดตแอปจาก GitHub แล้วกดยืนยัน ระบบตรวจและดาวน์โหลดรุ่นใหม่ เตรียมเครื่องมือก่อนเริ่มระบบใหม่
  5. รอให้ระบบกลับมาพร้อมใช้งาน หากหน้าจอยังค้างข้อความเริ่มใหม่ ให้รีเฟรชหรือเปิดทางลัด Desktop อีกครั้ง ไม่กดสั่งพิมพ์ระหว่างอัปเดต
  6. ตรวจผู้ส่ง ชื่อเครื่องพิมพ์ ลูกค้า และดาว แล้วทดลองฉลากจริง 1 ใบก่อนใช้งานต่อ
ไม่ต้องถอนติดตั้งหรือนำเข้า Excel ซ้ำ การอัปเดตโค้ดใช้ฐานข้อมูลเดิม ข้อมูลลูกค้า ดาว และผู้ส่งยังอยู่ การสำรองก่อนอัปเดตช่วยกู้กลับได้หากมีปัญหา

เครื่องที่ลงจาก ZIP

ปุ่มอัปเดตจาก GitHub ใช้ไม่ได้ ให้ผู้ดูแลสำรองและปิดระบบก่อนอัปเดต สำหรับการใช้งานระยะยาวให้ clone โค้ดรุ่นใหม่ในโฟลเดอร์ใหม่ เปิดเตรียมระบบ ปิดระบบ แล้วกู้ไฟล์สำรองตามหน้า 5 ตรวจเครื่องพิมพ์และสร้างทางลัดที่ตำแหน่งใหม่ก่อนส่งคืนผู้ใช้

หากอัปเดตไม่สำเร็จ

อ่านข้อความผลอัปเดต ถ้าขึ้นว่าเวอร์ชันล่าสุดแล้ว ให้ผู้ดูแลตรวจว่าปล่อยโค้ดไปสาขาเดียวกับเครื่องนี้หรือไม่ ถ้ามีไฟล์แก้ไขหรือลบค้าง ระบบจะไม่ทับไฟล์ ให้ผู้ดูแลบันทึกหรือจัดการการเปลี่ยนแปลงนั้นก่อน เมื่อเตรียมอัปเดตไม่ผ่าน ระบบเดิมยังทำงานได้ ผลการเริ่มระบบใหม่ตรวจได้ใน data/runtime.log

ไม่มีการอัปเดตตามเวลาอัตโนมัติ: การเปิดโปรแกรมหรือเข้า Windows ไม่ได้ดึงรุ่นใหม่ ผู้ใช้งานต้องกดปุ่มอัปเดตเมื่อผู้ดูแลแจ้งว่ามีรุ่นใหม่

6. เมื่อใช้งานไม่ได้

อาการตรวจและแก้เบื้องต้น
localhost เปิดไม่ได้ใช้ทางลัด Label Pro Max Local และรอระบบพร้อม ถ้าย้ายโฟลเดอร์ ให้เปิด start-label-pro-max-local.vbs ที่ตำแหน่งใหม่เพื่อสร้างทางลัดใหม่
ดับเบิลคลิก VBS ไม่ทำงานตรวจว่าแตก ZIP แล้ว และ Windows Script Host ไม่ถูกปิดโดยนโยบายองค์กร ถ้าถูกปิดให้ผู้ดูแลใช้ตัวเปิด PowerShell ที่ระบุใน README ไม่ต้องเปิดคำสั่งค้าง
เตรียมระบบครั้งแรกไม่ผ่านตรวจอินเทอร์เน็ตและสิทธิ์เขียนโฟลเดอร์ แล้วเปิดตัวเปิดใหม่ ดู data/launcher.log สำหรับข้อความผิดพลาด ไม่ลบ data/ เพื่อแก้ปัญหา
พอร์ต 3000 ถูกใช้ตรวจว่ามี Label Pro Max Local อีกโฟลเดอร์หรือแอปอื่นทำงานอยู่ ให้ผู้ดูแลจัดการโปรแกรมนั้น ไม่เปิด Label Pro Max Local สองชุดบนพอร์ตเดียวกัน
งานล้มเหลว / กระดาษไม่ออกตรวจไฟ USB กระดาษ สถานะเครื่องพิมพ์ และชื่อในตั้งค่า ดูข้อความผิดพลาดหน้าคิว รวมทั้งคิวของ Windows ก่อนกดพิมพ์ซ้ำ เพื่อไม่ให้ได้ฉลากซ้ำ
ฉลากถูกตัด / ขนาดผิดตรวจขนาดกระดาษในไดรเวอร์เป็น 100 × 150 mm และการตรวจจับฉลาก ทดลอง 1 ใบอีกครั้ง ถ้าข้อความยาวเกินให้ย่อข้อมูลที่อยู่
นำเข้า Excel ไม่ผ่านตรวจชื่อชีต PrintLabel และลำดับ A-D ไฟล์ไม่เกิน 10 MB ชื่อย่อ A ต้องไม่ว่าง
อัปเดตไม่ผ่านตรวจอินเทอร์เน็ต Git และการติดตั้งด้วย clone ถ้าขึ้นว่ามีไฟล์แก้ไขค้าง ให้ผู้ดูแลจัดการก่อน ไม่ทับโค้ดและข้อมูลทั้งหมด

ตรวจรับก่อนส่งให้พนักงาน

□ เปิดจาก Desktop ได้โดยไม่มี terminal ค้าง
□ ผู้ส่ง สาขา และเครื่องพิมพ์ถูกต้อง
□ ลูกค้าและรายการปักหมุดแสดงถูกต้อง
□ ทดลองฉลากจริง 1 ใบผ่าน
□ สำรองข้อมูลและคัดลอกออกจากเครื่องแล้ว
□ หลังเข้า Windows ครั้งถัดไป เปิดทางลัดใช้งานได้
